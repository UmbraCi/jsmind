🧠 jsMind - MultilineTextV2 Plugin Demo

Enhanced Plugin System Features

  • Synchronous Initialization: Plugin initializes before rendering, so multiline text displays correctly from the start
  • Lifecycle Management: Proper cleanup with beforePluginRemove() and beforePluginDestroy() hooks
  • Custom Rendering: Multiline text nodes render with pre-wrap and word-break styles
  • Textarea Editor: Edit multiline text with a textarea instead of input field
  • Dynamic Plugin Management: Add or remove plugins at runtime

Usage Example:

// 1. Import plugin
import jsMind from './src/jsmind.js';
import MultilineTextV2 from './src/plugins/jsmind.multiline-text-v2.js';

// 2. Register plugin (before creating instance)
jsMind.usePlugin(MultilineTextV2, {
    text_width: 250,
    min_height: 40,
    line_height: '1.6'
});

// 3. Create jsMind instance
const jm = new jsMind({
    container: 'jsmind_container',
    editable: true,
    theme: 'primary'
});

// 4. Show mind map with multiline text
jm.show({
    meta: { name: 'demo', author: 'test', version: '1.0' },
    format: 'node_tree',
    data: {
        id: 'root',
        topic: 'Root Node',
        children: [
            { id: 'node1', topic: 'Line 1\nLine 2\nLine 3' }
        ]
    }
});

// 5. Remove plugin dynamically (optional)
jm.removePlugin(MultilineTextV2);
